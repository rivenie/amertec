# Amertec Servece Company

Landing web de Amertec Servece Company: construcción, electricidad industrial, estructuras metálicas, drywall, gasfitería y sistemas de seguridad en Lima.

## Contenido

- `index.html`: la página completa (HTML, CSS y JavaScript en un solo archivo).
- `img/`: fotos y logo que usa la página.

## Publicar en GitHub Pages

1. Sube `index.html`, la carpeta `img` y este README a la raíz del repositorio.
2. Ve a **Settings → Pages**, elige **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`, y guarda.
3. La web queda en `https://<usuario>.github.io/<repositorio>/`.
